# Support

## Start here

- Read the [repository overview](README.md) and select the exact version you are using.
- Confirm its Unreal Engine boundary in the [compatibility matrix](COMPATIBILITY.md).
- Review the version-specific README, verification boundary, and [known issues index](KNOWN_ISSUES.md).
- For the current published snapshot, start with the [`PGX v0.1.1 · Unreal Engine 5.7.4` quickstart](versions/pgx-v0.1.1/ue-5.7.4/docs/getting-started/quickstart.md).
- Search existing GitHub issues before opening a new question.

## Good support requests

Include the exact PGX version or commit, Unreal Engine version, target platform, reproduction steps, expected result, observed result, and a small sanitized log extract when relevant.

Do not post credentials, proprietary source, licensed assets, complete project archives, or unrelated editor logs.

The project does not promise a response time during Development Preview. Questions with a reproducible case and a narrow scope are the easiest to act on.

## Security

Do not use a public support issue for suspected vulnerabilities. Follow the [security policy](SECURITY.md).

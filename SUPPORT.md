# Support

## Documentation and questions

- Start with the [README](README.md).
- Use the [public wiki](https://github.com/platanogames/PGX-Framework/wiki) for
  architecture, subsystem, tooling, and integration documentation.
- Search existing GitHub issues before opening a new question.

## Good support requests

Include the Unreal Engine version, PGX build or revision, target platform,
reproduction steps, expected result, actual result, and relevant sanitized log
extracts.

Do not post credentials, licensed assets, private source, or complete project
archives.

## Professional services

Training, onboarding, and studio engineering services are separate from the
Apache-2.0 framework license. See the contact information in the README.

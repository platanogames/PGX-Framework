# Security Policy

## Reporting a vulnerability

Do not publish suspected vulnerabilities, credentials, private project data,
or exploit details in a public issue.

Use GitHub private vulnerability reporting for this repository when available.
If that option is unavailable, contact the repository owner through the
verified [PlatanoGames GitHub profile](https://github.com/platanogames) and ask
for a private reporting channel before sharing sensitive details.

Include:

- affected PGX tag or commit;
- affected Unreal Engine version and platform;
- impact and prerequisites;
- minimal reproduction steps;
- a suggested mitigation, if known.

Do not attach proprietary project source, licensed assets, credentials, or a
complete game project.

## Supported versions

During Development Preview, security fixes target the latest published preview
unless a release notice states otherwise. Development branches and untagged
snapshots are not supported release artifacts.

PGX is not yet recommended for production use. This does not reduce the value
of responsible reports or the need to handle them privately.

# Support

## Start here

- Read the [README](README.md) and the release notes for your tag.
- Check [known issues](KNOWN_ISSUES.md).
- Follow the [preview evaluation guide](docs/getting-started/quickstart.md).
- Search existing GitHub issues before opening a new question.

## Good support requests

Include the exact PGX revision, Unreal Engine version, target platform,
reproduction steps, expected result, observed result, and a small sanitized log
extract when relevant.

Do not post credentials, proprietary source, licensed assets, complete project
archives, or unrelated editor logs.

The project does not promise a response time during Development Preview.
Questions with a reproducible case and a narrow scope are the easiest to act on.

## Security

Do not use a public support issue for suspected vulnerabilities. Follow the
[security policy](SECURITY.md).

## Training and services

Training, onboarding, and studio engineering services are separate from the

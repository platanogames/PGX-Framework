# Security policy

## Reporting a vulnerability

Do not publish suspected vulnerabilities, credentials, proprietary project
data, or exploit details in a public issue.

Use GitHub private vulnerability reporting when available. Otherwise, contact
the repository owner through the verified PlatanoGames profile with the
affected component or document, reproduction steps, impact, and suggested
mitigation.

## Current repository scope

This public repository currently distributes project documentation and the
Apache-2.0 license, not the complete source monorepo. Security reports about an
early-access build should identify the exact build or commit without attaching
private source or licensed assets.
